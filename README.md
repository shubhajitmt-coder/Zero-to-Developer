Zero-to-Developer 🚀

Zero-to-Developer is an Android application project created to practice and learn Android app development using Kotlin.

📱 About the Project

This project is part of my journey from a beginner to becoming a developer. It focuses on learning Android development through practical implementation and continuous improvement.

🛠️ Built With

- Kotlin
- Android Studio
- Gradle
- XML
- Git & GitHub

✨ Features

- Android application built with Kotlin
- Simple and user-friendly interface
- Beginner-friendly project structure
- Continuously updated as new features are learned and implemented

📂 Project Structure

app/
├── src/
│   └── main/
│       ├── java/        # Kotlin source code
│       ├── res/         # Layouts, images, strings, etc.
│       └── AndroidManifest.xml
├── build.gradle
└── proguard-rules.pro

🚀 Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and download the required dependencies.
4. Connect an Android device or start an emulator.
5. Build and run the application.

📦 Building the APK

You can build the APK using Android Studio or GitHub Actions.

Using Gradle:

./gradlew assembleDebug

After a successful build, the debug APK can normally be found at:

app/build/outputs/apk/debug/app-debug.apk
